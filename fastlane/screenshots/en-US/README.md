# Screenshots — Morser

Drop App Store screenshots here, named so they sort in the order you want them
shown. `deliver` infers the device from each image's pixel dimensions, so the
size has to be exact.

Required sizes (only the ones for platforms this app ships on):

| Target | Pixels |
|---|---|
| iPhone 6.9" | 1320 x 2868 portrait |
| iPad 13" | 2064 x 2752 portrait |
| Mac | 2880 x 1800 |
| Apple TV | 1920 x 1080 |

These are not generated: a screenshot is only worth shipping with real content
loaded, and an empty-state capture is worse than none.
